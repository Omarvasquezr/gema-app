Política de privacidad

Última actualización: 28 de septiembre de 2026

Gema es una asistente personal de uso exclusivo de Omar Vásquez. La única persona cuyos datos trata es el propio Omar.

Datos a los que accede

Con el permiso calendar.events de Google, Gema accede únicamente a los eventos de Google Calendar de Omar para:

  • leer su agenda y preparar resúmenes;
  • crear, mover o cancelar los recordatorios que él le pide.

No accede a ajustes del calendario, contactos, correo ni a ningún otro dato de la cuenta de Google.

Cómo se procesan

Gema se ejecuta en el ordenador personal de Omar. Para entender sus mensajes y redactar respuestas, los datos necesarios se procesan con modelos de Google Gemini a través de la API de Gemini. Si Gemini no está disponible, la petición puede atenderse con un modelo alternativo a través de OpenRouter. Las respuestas llegan a Omar por su chat privado de Telegram.

Almacenamiento

La autorización de Google se guarda solo en el ordenador de Omar, protegida por permisos de archivo. No existe ningún servidor propio ni base de datos externa.

Compartición

Los datos no se venden ni se comparten con terceros, más allá de los proveedores técnicos indicados arriba, que los procesan solo para generar cada respuesta. No se usan para publicidad.

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Revocar el acceso

El acceso puede retirarse en cualquier momento desde myaccount.google.com/permissions.

Privacy policy

Last updated: September 28, 2026

Gema is a personal assistant used exclusively by Omar Vásquez. The only person whose data it handles is Omar himself.

Data accessed

With the Google calendar.events permission, Gema accesses only Omar's Google Calendar events in order to:

  • read his agenda and prepare summaries;
  • create, move or cancel the reminders he asks for.

It does not access calendar settings, contacts, email or any other Google account data.

How data is processed

Gema runs on Omar's personal computer. To understand his messages and write replies, the necessary data is processed by Google Gemini models through the Gemini API. If Gemini is unavailable, the request may be handled by an alternative model through OpenRouter. Replies reach Omar through his private Telegram chat.

Storage

The Google authorization is stored only on Omar's computer, protected by file permissions. There is no dedicated server and no external database.

Sharing

Data is not sold or shared with third parties beyond the technical providers listed above, which process it only to generate each reply. It is not used for advertising.

Gema's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
